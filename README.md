# 🚀 ShopCraft - Premium Shopping & Productivity Ecosystem

**ShopCraft** is not just a shopping website; it's a high-end, premium ecosystem designed for tech enthusiasts, creators, and modern digital professionals. Built with cutting-edge technologies like **React 19**, **Tailwind CSS v4**, and **Framer Motion**, it offers a "tagda" (powerful) and seamless user experience.

---

## 🌟 Key Features (Kya Hai Isme?)

### 1. 🏁 Professional Landing Page
A high-conversion landing page that introduces the brand with stunning animations and clear calls to action. It sets the stage for a premium experience.

### 2. 🛡️ Advanced Authentication System
- **Multi-Mode Auth:** Login, Signup, and a dedicated **Forgot Password** flow.
- **Smart Security:** Wrong password triggers an automatic **OTP Simulation** to verify user identity.
- **OTP Verification:** 6-digit verification code for password resets and secure logins.
- **Protected Routes:** Shop content is only accessible after a successful login.

### 3. 🛍️ Premium Shopping Experience
- **Product Catalog:** A curated list of elite tech gear with dynamic filtering.
- **3-Step Checkout:** A smooth flow from **Cart -> User Details -> Payment -> Success**.
- **Quick View:** Instantly view product details without leaving the page.

### 4. 📝 Gear List (Productivity Todo)
A dedicated shopping todo list where you can manage what you need to buy or upgrade in your setup.

### 5. 🎨 Extreme Customization
- **Global Primary Color:** Change the website's accent color (Indigo, Cyan, Red, etc.) dynamically across the entire UI.
- **Dark/Light Mode:** Seamlessly switch between themes with smooth transitions.

### 6. 🎮 Entertainment Zone
- **Snake Game:** A classic game with high-score tracking using `localStorage`.
- **Tech Catch:** A fast-paced reaction game to test your speed.

### 7. 📸 Creative Tech Tools
- **Tech Vision:** Uses the **Camera API** to simulate an AR/Vision experience.
- **Tech Studio:** A workspace customization tool to visualize your ideal setup.

### 8. 🤖 ShopCraft AI Chatbot
An integrated AI-simulated chatbot with typing indicators and specific logic to help users navigate and solve queries.

### 9. 👤 User Profile Management
- **Image Upload:** Simulate real profile picture updates using `FileReader` and `localStorage`.
- **User Stats:** Track orders, points, and active subscriptions.

## 🛠️ Tech Stack (Kisse Bana Hai?)

- **Frontend:** [React 19](https://react.dev/) (Vite)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Newest Architecture)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router Dom v7](https://reactrouter.com/)
- **State Management:** Context API (Auth, Theme, Toast, etc.)
- **Persistence:** `localStorage` (No backend required for this version)

## 🚀 Getting Started (Kaise Chalayein?)

1. **Clone the project:**
   ```bash
   git clone <your-repo-link>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Default Login:**
   - **Email:** Any email
   - **Password:** `password123` (Wrong password will trigger OTP verification)

---

## 🗺️ Project Structure

- `/src/pages`: All main views (Home, Auth, Landing, Profile, etc.)
- `/src/components`: Reusable UI elements (Cart, Chatbot, Product Cards)
- `/src/context`: Global state management for Auth, Theme, and Toasts.
- `/src/assets`: Images and SVG icons.
